# Scene compositor dependencies

- Hyperframes engine 0.8.87: Apache-2.0, distributed with the dependency's LICENSE.
  https://github.com/heygen-com/hyperframes/blob/main/LICENSE
- Source Sans 3, via `@fontsource/source-sans-3` 5.3.0: SIL Open Font License 1.1.
- Source Code Pro, via `@fontsource/source-code-pro` 5.3.0: SIL Open Font License 1.1.

The two font packages include their complete LICENSE files. Rendering embeds the
pinned Latin WOFF2 files and records their SHA-256 hashes. The source fonts are
unmodified. Remotion is not a dependency.
